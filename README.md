# Activation energy prediction and conductivity selection in oxygen ion conductors
This repository contains the data supporting the study *Activation energy prediction and conductivity selection in oxygen ion conductors*.

| Folder | Contents |
| --- | --- |
| [Primary benchmark](./primary-benchmark/) | The 312 experimental records used in the main benchmark, with composition features, validation splits and held-out predictions. |
| [External validation](./external-validation/) | Observed and predicted activation energies for 34 literature records from eight source-connected groups. |
| [Oxygen vacancy analysis](./oxygen-vacancy/) | Neutral oxygen-vacancy formation energies, model predictions and tests of whether vacancy information improves experimental activation-energy predictions. |
| [LSGM conductivity selection](./lsgm-conductivity/) | Composition pairs, measured conductivities at 800 °C and the results of selecting candidates using predicted or reported activation energies. |

Each folder includes a README describing its files and how they relate to the analyses in the paper.
